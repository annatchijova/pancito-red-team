# Code of Conduct

PANCITO-RED-TEAM is a space for research, learning, and authorized adversarial
security testing. Everyone participating in the project is expected to help
keep its community welcoming, professional, and focused on defensive outcomes.

## Expected behavior

- Be respectful, constructive, and open to good-faith disagreement.
- Critique ideas and work without attacking people.
- Make technical discussions accessible and provide context when it helps.
- Keep testing within explicitly authorized systems and the project's stated
  defensive scope.
- Protect people's privacy and handle vulnerability details responsibly.

## Unacceptable behavior

- Harassment, discrimination, intimidation, threats, or sustained personal
  attacks.
- Publishing another person's private information without permission.
- Encouraging or coordinating unauthorized access, disruption, or harm to
  real-world systems or people through project spaces.
- Knowingly sharing malicious or abusive content in project discussions.
- Retaliating against someone for raising a concern in good faith.

## Scope

This code applies in project spaces, including issues, pull requests, code
reviews, discussions, and events run by the project. It also applies when someone
is acting publicly as a project representative.

## Reporting and enforcement

Report conduct that concerns you privately to the project maintainer through
[the maintainer's GitHub profile](https://github.com/annatchijova). Please
include what happened, where it happened, and any context needed to review it.
Reports will be handled as confidentially as practical. The maintainer will
review each report, may ask for more information, and will take action they
consider appropriate. Actions may include a warning, removal of content,
temporary restrictions, or exclusion from project spaces. Retaliation for a
good-faith report is not acceptable.

This policy is not a substitute for the authorization and safety boundaries in
the project documentation. A respectful discussion does not authorize testing
outside an approved scope.
